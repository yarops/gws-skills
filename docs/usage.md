# Использование

[Главная](../README.md) · [Установка и обновление](installation.md)

## Через агента

После установки откройте новую сессию агента и проверьте, что доступны
`gws-drive` и `gws-sheets`. Каталог установки должен быть каталогом скиллов,
который читает ваш агент.

Опишите задачу обычным языком: какой файл найти или скачать, какую таблицу
создать, какие листы и колонки нужны. Для существующей таблицы дайте ссылку,
для файла или папки — ссылку либо название и место поиска.

Правила операций находятся в [скилле Drive](../gws-drive/SKILL.md)
и [скилле Sheets](../gws-sheets/SKILL.md). Агент проверяет CLI и авторизацию
перед обращением к Google, а результат изменения — после выполнения.

## Оболочка инструмента агента

Команды разделены по оболочкам: в `SKILL.md` находятся правила выбора,
а в справочниках каждого скилла — соответствующие примеры:

| Скилл | Bash/zsh | PowerShell 7.3+ |
|---|---|---|
| Drive | [Команды Bash](../gws-drive/references/bash.md) | [Команды PowerShell](../gws-drive/references/powershell.md) |
| Sheets | [Команды Bash](../gws-sheets/references/bash.md) | [Команды PowerShell](../gws-sheets/references/powershell.md) |

Агент выбирает справочник по оболочке своего инструмента выполнения, включая
Bash в WSL/Git Bash; ОС сама по себе выбор не определяет. Для PowerShell нужны
`gws.exe`, версия 7.3+ и передача аргументов в режиме `Windows` либо `Standard`.
Справочник описывает настройку отдельного процесса без изменения профиля.
Установка оболочек и изменение пользовательского профиля не выполняются.

## Прямой запуск помощника Sheets

Помощник `create_tracker.py` работает на Python 3.9+ без сторонних пакетов
и вызывает `gws` напрямую. Он создаёт таблицу, записывает заголовки буквальным
текстом и применяет [общий стиль](../gws-sheets/assets/header_style.json).
Вызов с одним листом и JSON-массивом заголовков описан в справочнике Sheets
для выбранной оболочки.

Для нескольких листов используйте `--config FILE`: JSON содержит название
таблицы и массив листов с названиями и заголовками.
Пример — [tracker_example.json](../gws-sheets/assets/tracker_example.json).
Для своей таблицы подготовьте конфигурацию с нужными названиями и колонками.

Команды ниже выполняются из корня репозитория. Для установленной копии
используйте пути относительно каталога установленного `SKILL.md`.

```sh
python3 ./gws-sheets/scripts/create_tracker.py --config ./gws-sheets/assets/tracker_example.json
```

На Windows используйте PowerShell:

```powershell
py -3 ./gws-sheets/scripts/create_tracker.py --config ./gws-sheets/assets/tracker_example.json
```

Если `py` недоступен, используйте установленный Python 3 через `python`.

## Восстановление настройки таблицы

Если таблица создана, но настройка прервалась, передайте её ID и тот же файл
конфигурации. Это завершит настройку без создания дубля:

```sh
python3 ./gws-sheets/scripts/create_tracker.py --resume SPREADSHEET_ID --config ./gws-sheets/assets/tracker_example.json
```

В PowerShell:

```powershell
py -3 ./gws-sheets/scripts/create_tracker.py --resume SPREADSHEET_ID --config ./gws-sheets/assets/tracker_example.json
```

Режим повторно записывает заголовки первой строки и оформление всех листов
из конфигурации, включая уже настроенные. Используйте его для восстановления
созданной таблицы. При неизвестном результате создания сначала найдите файл
в Drive, прежде чем повторять создание. Подробные ограничения — в скилле Sheets.
