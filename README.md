# gws skills

Скиллы для Claude и других агентов, которые работают с Google Drive и Google
Sheets через Google Workspace CLI (`gws`). Агент получает инструкции и готовые
команды для выполнения ваших задач.

## Возможности

- **gws-drive:** поиск файлов, работа с папками, загрузка, скачивание и управление доступом.
- **gws-sheets:** чтение и запись ячеек, создание оформленных таблиц с одним или несколькими листами.

## Требования

- Установленный и авторизованный `gws`; на Windows — исполняемый `gws.exe`.
- Bash/zsh или PowerShell 7.3+ для команд агента.
- Python 3.9+ для помощника создания таблиц Sheets, без сторонних пакетов.

Установщик скиллов не устанавливает зависимости. Если `gws` отсутствует или
недоступен в `PATH`, сначала выполните [настройку окружения](docs/installation.md#зависимости-и-отсутствие-gws).

## Установка

Сначала установите CLI и настройте доступ к Google по
[инструкции для Linux, Windows и macOS](docs/installation.md#установка-gws).
В ней есть настройка OAuth через `gcloud` и вручную, проверка доступа и
решения частых проблем.

Склонируйте репозиторий или распакуйте архив и перейдите в его каталог.
На macOS/Linux установщик требует Bash:

```sh
# Для пользователя
./install.sh --dest "$HOME/.agents/skills"

# В конкретный проект
./install.sh --dest /path/to/project/.agents/skills
```

На Windows используйте PowerShell 7.3+:

```powershell
# Для пользователя
pwsh -NoProfile -File ./install.ps1 -Dest "$HOME/.agents/skills"

# В конкретный проект
pwsh -NoProfile -File ./install.ps1 -Dest 'C:\Projects\my-project\.agents\skills'
```

Каталог назначения — родительская папка скиллов: внутри появятся `gws-drive/`
и `gws-sheets/`. Можно указать другую папку, которую читает ваш агент.
Устанавливаются копии: последующие правки репозитория их не меняют.

## Обновление

Получите новую версию репозитория и запустите установщик с явным флагом обновления:

```sh
./install.sh --dest "$HOME/.agents/skills" --upgrade
```

```powershell
pwsh -NoProfile -File ./install.ps1 -Dest "$HOME/.agents/skills" -Upgrade
```

Обновление заменяет отличающиеся папки целиком, включая ручные правки.
Предыдущие версии сохраняются в `DEST/.gws-skills-backups/`; установщик выводит
точный путь. Подробности и восстановление — в [инструкции установки](docs/installation.md).

## Использование

Откройте новую сессию агента и проверьте, что он обнаруживает оба скилла.
Затем опишите задачу обычным языком, например:

- «Найди на Google Drive файл с названием “Отчёт за сентябрь”».
- «Скачай этот файл с Google Drive в папку проекта: <ссылка на файл>».
- «Создай Google-таблицу “Контент-план” с листами “Статьи” и “Ключи”; на каждом нужны колонки “Название” и “Статус”».

Для существующих файлов и таблиц передавайте ссылки или названия и место поиска.
Агент проверит доступность `gws` и авторизацию перед обращением к Google.
